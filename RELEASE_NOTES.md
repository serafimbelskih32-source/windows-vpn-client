**Обновление программы стало надёжнее.**

- **У каждой копии программы своя папка обновлений.** Если у тебя две копии (например, одна в «Загрузках», другая на рабочем столе), раньше они делили одну папку: первая забирала скачанный файл, вторая оставалась без обновления и просто запускала себя заново. Теперь каждая копия скачивает и ставит обновление отдельно.
- **Установка идёт один раз.** Повторный щелчок по «Установить» или второй запуск во время установки больше не создают второй процесс замены (из-за этого после одного обновления появлялось два окна).
- **Файл проверяется перед заменой.** Новая версия копируется рядом, сверяется по контрольной сумме и только потом одним действием заменяет старую. Испорченный файл не заменит рабочую программу.
- **Окно закрывается без ошибок** при установке обновления, оставшиеся от обновления файлы убираются при следующем запуске.
- **Проверка в сборке.** При каждой сборке на GitHub собранная программа (Windows и Linux) заменяет сама себя другим файлом и должна запуститься снова. Если это не работает, релиз не выйдет. Именно такую поломку не видят обычные тесты.
- Из 1.2.2 остаётся исправление перезапуска после обновления, из 1.2.1 остаются «Быстрейший из списка» без серверов твоей страны (если там блокируют) и чёткие значки.

Если ты обновляешься с версии 1.2.1 или старше, окно «Failed to load Python DLL» может появиться один раз: код перезапуска в тех версиях старый. Обновление при этом уже установлено, просто запусти программу заново. С 1.2.2 так больше не будет.

**Важно про Linux и macOS.** Эти версии собираются и проходят автоматические проверки на GitHub, но я не мог запустить их на настоящем компьютере с Linux или Mac, поэтому значок в трее и перезапуск после обновления на macOS там не проверены вживую. Если что-то не работает, открой [Issue](https://github.com/serafimbelskih32-source/windows-vpn-client/issues) и приложи текст из раздела «Лог».
