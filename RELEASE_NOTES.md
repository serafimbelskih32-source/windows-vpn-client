**Если при включённом VPN сайты не открываются: программа теперь находит частую причину и предлагает исправить.**

- **Забытый прокси Windows.** Когда VPN-клиент (например, Karing) закрыли или компьютер выключили, клиент часто оставляет в Windows включённый прокси на своём адресе, например `127.0.0.1:3067`. Самого клиента уже нет, и браузер с большинством программ упираются в мёртвый адрес: «нет интернета», даже когда наш VPN подключён. Теперь при подключении программа проверяет такой прокси и, если он не отвечает, объясняет простыми словами и предлагает кнопкой «Отключить прокси». Если прокси работает (другая программа включена сейчас), она только предупреждает, что браузер идёт через него, а не через этот VPN.
- **Загрузка подписок и проверка обновлений** больше не спотыкаются о такой мёртвый прокси: они обходят его сами.
- **Окно не выше экрана.** Раньше при открытых «Настройках» нижняя строка («Лог», «Настройки», версия) могла уехать за край экрана, и до расширенных настроек было не добраться. Теперь при нехватке высоты сжимается список серверов, а нижняя строка остаётся на месте.

Из 1.2.3 остаются: понятные сообщения об ошибках, расширенные настройки (двойной щелчок по «Настройки»), защита от плохих строк подписок, автоматическое переподключение и надёжное обновление программы.

Если ты обновляешься с версии 1.2.1 или старше, окно «Failed to load Python DLL» может появиться один раз: тогда просто запусти программу заново, обновление уже установлено.

**Важно про Linux и macOS.** Эти версии собираются и проходят автоматические проверки на GitHub, но я не мог запустить их на настоящем компьютере с Linux или Mac. Проверка прокси Windows работает только в Windows. Если что-то не работает, открой [Issue](https://github.com/serafimbelskih32-source/windows-vpn-client/issues) и приложи текст из раздела «Лог».
